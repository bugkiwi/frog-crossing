# 🐸 金山青蛙过河 - 儿童趣味英语打字练习网页版

> 致敬经典《金山打字通·青蛙过河》，面向现代儿童全新设计的网页版打字练习与英语单词过河游戏！

## 🌟 核心特色与交互升级

本游戏在忠实保留原版金山打字通“荷叶漂流、按键跳跃、护送青蛙安全过河”的核心玩法基础上，针对现代儿童的认知特点和打字学习习惯进行了全方位的交互体验升级：

1. **生动可爱的萌系视效 (Child-friendly Visuals)**
   - 全新矢量绘制的小青蛙：具备眨眼微笑、张嘴欢呼、伸腿大跳跃、落水眩晕等丰富表情与物理抛物线跳跃动画。
   - 动态河道水流：多层荷叶错位双向平滑漂流、水波涟漪、游动小鱼与粉色睡莲花苞点缀。
   - 目标聚焦光圈：当前可跳跃的目标荷叶带有跳动的黄色光圈与向下引导箭头，孩子一眼就能看准目标。

2. **全流程原生音效与纯正英文发音 (Web Audio & Native TTS)**
   - **自研 Web Audio API 音效合成器**：无需依赖外部 MP3 音频文件，清脆木质按键音（连击音调升阶）、青蛙欢快“呱呱”叫声、Q弹弹簧跳跃声、落水扑通声、终点欢呼琶音，零加载延迟且永远不报错。
   - **英语原生真人发音 (Web Speech API)**：小青蛙每一次跳跃落位，都会以适合二年级孩子的清晰语速朗读该单词，实现“看词 - 拼写 - 听音 - 知义”闭环记忆。
   - **中文释义气泡**：荷叶下方贴心标注对应汉字释义，强化单词理解。

3. **专为低年级打造的“儿童指法小键盘” (Interactive Keyboard)**
   - 底部内置直观的 QWERTY 虚拟键盘，采用标准色彩划分左右手各手指的分工（左手小指粉色、无名指橙色、中指黄色、食指绿色、大拇指紫色等）。
   - 实时根据目标单词指示：“当前目标：按键 [A] ➔ 左手小指”，对应键位产生呼吸光晕与跳动动画，帮助二年级初学打字的孩子建立标准盲打指法习惯。
   - 支持一键收起/展开，不遮挡河道视野。

4. **零挫败感的贴心难度分级 (Game Difficulties)**
   - **🌱 轻松初级 (推荐初学者)**：荷叶漂移平缓且**永远不会沉没**，即便孩子找键较慢，小青蛙也绝不会落水，充分保护学习积极性！
   - **🌊 经典标准 (原版手速)**：原汁原味的金山节奏，适度漂流速度，兼顾趣味与锻炼。
   - **⚡ 极速进阶**：荷叶快速漂流，适合打字手速已有基础的小朋友冲刺高分。

5. **智能通关激励与连击机制 (Combos & Victory)**
   - 连击加成（🔥 连击 x5、x10 等），每只青蛙成功上岸均在终点岛保留展示。
   - 通关后触发全屏七彩纸屑礼花动画（Confetti），生成 3 星评级、打字准确率、KPM/WPM 键盘手速统计卡。

## 📚 课程与教材体系 (特别定制)

### 1. 《新交际英语 二年级上册 (外研社)》重点推荐
全面覆盖教材全部核心单元，包含词形、音标与释义：
- **Unit 1: Feelings & States (情绪与状态)**：`sad`, `angry`, `tired`, `hungry`, `thirsty`, `happy`, `fun`, `show`, `turn`, `feel` 等。
- **Unit 2: Food & Meals (美食与餐饮)**：`apple`, `banana`, `rice`, `noodle`, `milk`, `bread`, `cake`, `sweet`, `egg`, `soup`, `dinner`, `yummy` 等。
- **Unit 3: Weather (神奇的天气)**：`sun`, `sunny`, `windy`, `rainy`, `rainy`, `snowy`, `warm`, `cold`, `hot`, `weather` 等。
- **Unit 4: Seasons & Time (四季与时间)**：`spring`, `summer`, `autumn`, `winter`, `season`, `year`, `clock`, `time` 等。
- **Unit 5: Clothes (漂亮衣物)**：`hat`, `shirt`, `skirt`, `coat`, `shoe`, `put`, `dress`, `cap` 等。
- **Unit 6: Daily Life & Play (日常交际与活动)**：`jump`, `kite`, `card`, `house`, `make`, `wait`, `play`, `walk` 等。
- **全册大通关**：30+ 重点词汇综合大闯关！

### 2. 《北京版小学英语 二年级上册 (北京出版社)》
- Unit 1: 日常作息 (`cook`, `read`, `write`, `draw`, `clean`, `bed`, `school`)
- Unit 2: 交通与出行 (`bus`, `car`, `bike`, `walk`, `train`, `plane`)
- Unit 3: 我们爱运动 (`sport`, `football`, `basketball`, `run`, `swim`)
- Unit 4: 七彩一星期 (`Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`...)
- Unit 6: 萌宠动物乐园 (`bear`, `duck`, `elephant`, `tiger`, `rabbit`, `monkey`...)

### 3. 《26字母与三字母萌词启蒙》
- 26个单字母快速反应、3字母简单词汇（`cat`, `dog`, `sun`, `run`, `big` 等）。

## 📄 PDF 教材智能导入功能

用户可随时上传自有的英语教材 PDF 或粘贴单词文本：
1. 点击顶部 **“导入PDF教材”** 或打开词库管理界面中的 **“上传教材 PDF / 自定义词库”** 选项卡。
2. 拖入任何小学英语教材的 PDF 文件：
   - 内置前端 `pdfjs-dist` 解析引擎，纯本地浏览器端处理，绝不泄露隐私。
   - 自动扫描每一页文字，智能过滤停用词与标点符号，提取英文字词。
   - 自动连接小学核心词典，为提取的生词自动补全中文汉字释义。
3. 支持直观预览词表、自由增删不需要的生词，点击 **“保存并立即开始”** 即可生成专属打字关卡！
4. 导入的词库持久化保存在浏览器本地（LocalStorage），下次打开依然有效。

## 🚀 本地运行与部署指南

### 环境要求
- Node.js >= 18
- 现代主流浏览器（Chrome / Edge / Safari / Firefox）

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
```
启动后在浏览器打开 `http://localhost:5173` 即可开始游玩。

### 生产打包构建
```bash
npm run build
```
构建产物输出至 `dist/` 目录，可直接托管至任何静态 Web 服务器、Vercel、GitHub Pages 或内网环境。

## 🎮 操作按键说明

| 按键 | 功能说明 |
| :--- | :--- |
| **A ~ Z** | 敲击荷叶上的对应英文字母 |
| **Space 空格** | 当小青蛙到达第4层水流时，敲击空格一跃上岸；或在虚拟键盘中替代空格输入 |
| **Esc 键** | 清除当前正在输入的单词进度，重新瞄准 |
| **鼠标点击** | 可直接点击河面上的任意目标荷叶切换瞄准，或点击小键盘按键打字 |
